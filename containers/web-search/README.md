# web-search

The container has Python and playwright-cli installed. Playwright expects a config file, such as [.playwright/cli.config.json](.playwright/cli.config.json).

See [AGENTS/web-search.md](../../AGENTS/web-search.md) for agent instructions.

## Brave search API

To use the Brave search API, copy the API key to `.pi/secrets` and include instructions in `AGENTS.md`. See [AGENTS/web-search.md](../../AGENTS/web-search.md).
