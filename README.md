# AI Paraphernalia

This repository contains remnants from my agentic coding projects.

Most of these files were at least partially AI-written and may be out of date because of changes in the models or other software. Though some files are fairly general, they are collected here merely as examples and are not meant to be used as is.

## Index

### prompts

- [**brainstorm.md**](prompts/brainstorm.md): general prompt for investigating approaches to reach a goal; splits the results into approaches that use only existing software and hardware and those that have a custom-made component; needs tools for reading web pages.

- [**complete-todo.md**](prompts/complete-todo.md): used in `webgallery` to ask the agent to complete a single small task from a todo list and commit the changes to a new branch; the todo list was generated by AI, with some manual adjustments; differentiates the agent's git commits from mine by changing the username, a feature I wouldn't replicate.

- [**research.md**](prompts/research.md): general prompt for investigating existing software that performs a given function; needs tools for reading web pages.

### AGENTS

Copies of `AGENTS.md` from previous projects.

- [**go-tests.md**](AGENTS/go-tests.md): used in `webgallery`; contains an only moderately successful attempt to restrain the agent's tests.

- [**web-search.md**](AGENTS/web-search.md): used in `knitware-research`; contains a description of the tools installed and instructions for using the Brave Search API.

### containers

- [**go-with-image-tools**](containers/go-with-image-tools/): used in `webgallery`; installs exiftool and libvips.

- [**web-search**](containers/web-search/): used with the `brainstorm` prompt to research methods to improve my houseplants' health and projects for a Reachy Mini, and with the `research` prompt to investigate software for creating and publishing knitting patterns; installs tools for web search.
